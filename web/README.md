# SKY şema karşılaştırma arayüzü

React/TypeScript/Vite, shadcn/ui/Radix, Tailwind ve TanStack Table.

`npm ci`, `npm test`, `npm run build`. Geliştirme: `npm run dev`, API 8800
portunda olmalıdır. `dist/` Python sunucu tarafından servis edilir. Bütün
kayıtlar gerçek `/api` üzerinden gelir, örnek başarı sayacı yoktur.

Kurulum: [UI çalıştırma ve dağıtım](../docs/UI_CALISTIRMA_VE_DAGITIM.md).
